> **全景大數據・嚴謹治學公允審定版**  
> 收錄澳門非高等教育自 2014/2015 學校年度設立「卓越表現教師」榮譽以來，**第 1 屆至第 11 屆（2014/2015 – 2024/2025）累計 171 位獲獎教師之權威完整檔案**。經澳門教育及青年發展局（DSEDJ）歷屆官方頒授典禮特刊逐頁 OCR 視覺對校，全面更正早期網絡爬蟲的 28 項重大歷史誤植。

## 🧭 【學校行政會——卓越教師孵化推進行動路線圖】

```
┌────────────────────────────────────────────────────────────────────────┐
│ 1. 體制改革：成立校級「申報專班」（副校長掛帥，教研主任+文宣主筆護航）  │
│ 2. 梯隊建設：建立「3+3 名師儲備池」（3位近期衝刺 + 3位中青年種子）      │
│ 3. 賽道突圍：重點主攻「小學、幼教、德育特色」專屬保護名額              │
│ 4. 前置成果：全面攻堅教青局《教學設計獎勵計劃》（獲獎第一硬通貨）      │
│ 5. 文本精造：嚴守 30 頁紅線，進行雜誌級排版與可視化數據論證             │
│ 6. 答辯演練：於每年 1 月組織校外專家進行 2-3 輪「全真模擬專家面試」     │
└────────────────────────────────────────────────────────────────────────┘
```

### 未來參選之行政會核心決策指引精華：
1. **提早 3 年建立「卓越種子人才庫」與蓄水池機制**：破除臨時拼湊，鎖定教齡 8–15 年之教學骨幹，賦予校本新課程研發與重點專案職權。
2. **鎖定顯性標誌性成果（國際/全國競賽金牌與教學成果獎）**：指導學生在國際奧賽（IMO/ISEF/IOI/iGEM）突破，申報國家級/特區級教學成果獎。
3. **避開數理紅海，策略性進軍「小學、幼教、特職、全人」突圍藍海**：瞄準小學整本書閱讀、幼兒感統蒙氏、特教個別化計劃（IEP）及職教課程協調。
4. **凝練「教育家精神」與生命蛻變敘事**：文本嚴守 30 頁紅線，提煉「教育格言＋痛點獨創破解法＋1至2位被徹底改變人生命運的典型學生故事」。
5. **設立校級申報專班與專家預評審**：文宣專班精造排版，每年 1 月力邀專家開展 2-3 輪全真模擬答辯面試。

## 🔍 重大勘誤與學術嚴謹性保證

本項目針對早期網絡爬蟲同名誤植、任教科組嚴重偏差進行了徹底的特刊原文審核，更正了多達 28 項重大錯誤（如王世澤老師為小學數學科組長而非中學物理；劉貳和老師為中學視覺藝術博士而非數學；郭桂豪老師為中學歷史名師而非物理；姚曉暉老師為中學生物科及 ISEF 教練而非化學；鍾子程老師為中學歷史名師而非視覺藝術等）。

對尚未正式印發紙本特刊專冊的少數公立學校獲獎者（如林嘉艷老師、陳雯雯老師），嚴格加註 `[待進一步官方確認]`，維持最高客觀標準。
